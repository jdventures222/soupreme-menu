# soupreme.fyt.life

The QR table menu for Soupreme Noodle Co., Whittier (13817 Whittier Blvd, Whittier, CA 90605), served by GitHub Pages from `main` at the repo root.

The menu is built in the private brand repo (`kei-brand-menus`, brand folder `soupreme`) and copied here to publish; edit the source there, never the built files here. `CNAME` holds the custom domain: keep it when copying a new build here (never sync with `--delete` over it).
